## Instalação rápida

[Baixar](https://github.com/emanuelz-martins/clique-limpo/releases/latest/download/Clique-Limpo.zip) · [Guia completo](https://github.com/emanuelz-martins/clique-limpo#instalação) · [Versões](https://github.com/emanuelz-martins/clique-limpo/releases)

1. Baixe o `Clique-Limpo.zip` e extraia em uma pasta
2. Abra `chrome://extensions` (Chrome) ou `edge://extensions` (Edge)
3. Ative **Modo do desenvolvedor**
4. Clique em **Carregar sem compactação**
5. Selecione a pasta `clique-limpo`

## Como usar

Abra um site, clique no ícone do Clique Limpo e pressione o botão com a carinha. A proteção ativa automaticamente.

| Ação | O que acontece |
| --- | --- |
| Ativar proteção | Protege o site na aba e recarrega uma vez |
| Navegar no mesmo site | Mantém a proteção ativa |
| Abrir nova aba separada | Começa desativada (mesmo se o URL for igual) |
| Trocar de aba | Pausa; volta quando você retorna |
| Ir para outro site | Limpa a ativação |

## Recursos

- 🛡️ **Camadas invisíveis** — detecta e oculta elementos transparentes suspeitos
- 🚫 **Pop-ups bloqueados** — intercepta aberturas forçadas de janelas
- 📊 **Rastreadores** — bloqueia domínios de rastreamento conhecidos
- 🎬 **Ajustes de player** — compatibilidade com configurações de vídeo
- 🖱️ **Controle manual** — você escolhe quais elementos ocultar
